# unplayable01.github.io

Personal portfolio for Harine (unplayable01). Plain HTML + CSS, no build step.
Design follows the **Linear** style from Refero Styles (dark "midnight precision instrument",
Inter + mono, hairline borders, one acid-lime primary action).

## Deploy on GitHub Pages
1. Create a new **public** repo named exactly `unplayable01.github.io`.
2. Upload everything in this folder (index.html, style.css, assets/, .nojekyll) to the repo root.
3. Repo → Settings → Pages → Source: "Deploy from a branch", Branch: `main` / `(root)` → Save.
4. In a minute or two the site is live at https://unplayable01.github.io

## Editing
- Copy lives in `index.html`; colours/spacing are tokens at the top of `style.css`.
- Swap media in `assets/` (keep the same filenames, or update the src).
