Technical Lead2025–26 · Team project · GAM200

TTBEngine & Tilt Tilt Boom

A 2D physics engine built from scratch in C++ on an entity–component–system core, with an ImGui editor, Lua scripting and its own installer, plus the game that ships on it. As technical lead I owned the engine and debugging tools, and ended up the top committer.

What I built

  • Deterministic replay system with binary serialization: records whole level runs, including resets, timer and physics state, so playback matches the original. Feeds a per-level best-time leaderboard.
  • Lua scripting integration: attach and create scripts from the editor with hot-reload, wired into the game-state manager.
  • Controller system: Bluetooth gamepad support, gyro aiming on two axes with recalibration, haptic rumble, and controller navigation across every menu.
  • Pooled memory manager with a live comparison against normal allocation, plus fixing memory leaks in the debug editor.
  • Editor tooling: rendering-layer system, visual prefab editor, universal undo, docked script viewer, audio manager UI with cross-state fades.
  • Original soundtrack: composed all the music for the main menu and every level. Listen →
  • Build & ship: split engine / editor / game into separate CMake targets, a build-size analyzer, and an Inno Setup installer with FMOD and licences.

Solo2026 · Python · Windows

Aaron the Guard Dog

A webcam guard dog for Windows. Aaron recognises my face, locks the PC when a stranger sits down, and reports to me on Telegram. Wake him by voice, put him to sleep with a hand gesture, check on him from my phone.

How it works

  • Three cooperating processes: a lightweight Telegram listener that's always on, a headless guard that owns the camera, and an offline voice-wake process.
  • Graded response: total strangers lock the PC instantly; faces that partly match someone trained trigger a 10-second Telegram “do you know them?” prompt.
  • Speaker-verified wake word: “Wake up Aaron” only works in my voice.
  • Gestures via MediaPipe: hold an open palm to sleep, custom gestures mapped to actions.
  • Evidence archive: timestamped stranger and unlock photos saved by day, even if Telegram is down.
