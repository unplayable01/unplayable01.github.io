Technical Lead2025–26 · Team project · GAM200

TTBEngine & Tilt Tilt Boom

A 2D physics engine built from scratch in C++ on an entity–component–system core, with an ImGui editor, Lua scripting and its own installer, plus the game that ships on it. As technical lead I owned the engine and debugging tools, and ended up the top committer.

  • Deterministic replay system with binary serialization: records whole level runs, including resets, timer and physics state, and feeds a per-level best-time leaderboard.
  • Lua scripting: attach and create scripts from the editor with hot-reload, wired into the game-state manager.
  • Controller system: Bluetooth gamepads, two-axis gyro aiming with recalibration, haptic rumble, controller navigation across every menu.
  • Pooled memory manager with a live comparison against normal allocation, plus fixing leaks in the debug editor.
  • Editor tooling: rendering layers, visual prefab editor, universal undo, docked script viewer, audio manager UI with cross-state fades.
  • Original soundtrack: all the music for the main menu and every level. Listen
  • Build & ship: separate CMake targets for engine / editor / game, a build-size analyzer, and an Inno Setup installer.

Solo2026 · Python · Windows

Aaron the Guard Dog

A webcam guard dog for Windows. Aaron recognises my face, locks the PC when a stranger sits down, and reports to me on Telegram. Wake him by voice, put him to sleep with a hand gesture, check on him from my phone.

  • Three cooperating processes: an always-on Telegram listener, a headless guard that owns the camera, and an offline voice-wake process.
  • Graded response: strangers lock the PC instantly; partial matches trigger a 10-second “do you know them?” prompt.
  • Speaker-verified wake word: “Wake up Aaron” only works in my voice.
  • Gestures via MediaPipe: open palm to sleep, custom gestures mapped to actions.
  • Evidence archive: timestamped stranger and unlock photos saved by day, even if Telegram is down.
